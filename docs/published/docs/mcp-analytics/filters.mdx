Use the filters above MCP analytics to narrow the data in Overview, Tool quality, Activity, and Sessions. The same filters apply to individual tool reports.

Select **Add filter** to choose an MCP property, event property, or feature flag. Add more filters to narrow the results further. Select **Clear filters** to remove the property filters.

The internal users menu controls whether the results include users covered by your project's internal and test user filters. To exclude them, select **Internal users included** and then **Exclude internal and test users**. If the option is unavailable, select **Configure internal and test users** first.

Property and internal user filters remain selected when you switch between MCP analytics sections. They are also saved in the URL, so a link opens with the same filters. Select **Refresh** to load the latest data with the current filters.
