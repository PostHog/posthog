---
title: Share of calls by harness
---

The MCP Analytics dashboard shows tool calls by harness as horizontal bars, ranked from most to fewest calls.
Each row shows the harness name and logo, its call count, and its percentage of all calls in the selected filters and date range.

Colors stay consistent when rankings change. Claude harnesses use shades of orange, OpenAI harnesses use shades of blue, and other harnesses use stable palette colors.
The existing **Other** category stays gray and includes calls whose client identity does not match a recognized harness.

Scroll within the card to see every harness. Percentages include all returned harnesses, including rows below the visible area and Other.
Hover over a bar to see the full harness name, calls, share, sessions, and error rate.
