PostHog has an HTTP endpoint that accepts deliveries from an [Amazon Data Firehose](https://docs.aws.amazon.com/firehose/latest/dev/what-is-this-service.html) stream, so you don't have to run a forwarder. A CloudWatch subscription filter copies a log group into the stream, and the stream posts batches to PostHog. Everything runs in your AWS account.

This works for any CloudWatch log group: Lambda, RDS, ECS, API Gateway, VPC flow logs, and anything your own code writes.

## Before you start

You need:

- Your project API key, from **Settings > Project > Project API key**.
- Permission in AWS to create a Firehose stream, two IAM roles, an S3 bucket, a CloudWatch log group, and subscription filters.
- The names of the log groups you want to send.

Firehose bills for the data it ingests. Check the [Firehose pricing page](https://aws.amazon.com/kinesis/data-firehose/pricing/) before you subscribe a high-volume log group.

## Your endpoint URL

| PostHog Cloud | Endpoint URL                                      |
| ------------- | ------------------------------------------------- |
| US            | `https://us.i.posthog.com/i/v1/logs/aws/firehose` |
| EU            | `https://eu.i.posthog.com/i/v1/logs/aws/firehose` |

If you self-host, use your own ingestion host with the same path. Firehose delivers only to HTTPS endpoints, so the host needs to be reachable from AWS over HTTPS with a valid certificate.

## Set it up with CloudFormation

The template below creates the stream, the roles, a backup bucket, a log group for delivery errors, and a subscription filter for one log group.

1. Save it as `posthog-cloudwatch-logs.yaml`.
2. Open **CloudFormation > Create stack > With new resources**, choose **Upload a template file**, and pick the file.
3. Fill in `PostHogEndpointUrl`, `PostHogAccessKey` (your project API key), and `LogGroupName`. Optionally set `FilterPattern` to forward only some lines.
4. Create the stack.

To add more log groups, run one command per group with the stack's `DeliveryStreamArn` and `LogsToFirehoseRoleArn` outputs. They share the stream, so you don't need a second stack. Each group can have its own filter pattern. This one forwards only warnings and errors:

```bash
aws logs put-subscription-filter \
  --log-group-name /aws/ecs/search-indexer \
  --filter-name posthog-logs \
  --filter-pattern '?ERROR ?WARN' \
  --destination-arn <DeliveryStreamArn> \
  --role-arn <LogsToFirehoseRoleArn>
```

If you manage several log groups, the [Terraform configuration](#set-it-up-with-terraform) takes all of them with their patterns in one place.

```yaml
AWSTemplateFormatVersion: '2010-09-09'
Description: >-
  Streams one CloudWatch log group into PostHog Logs through an Amazon Data Firehose
  HTTP endpoint destination. Add more subscription filters that point at the same stream
  to include more log groups.

Parameters:
  PostHogEndpointUrl:
    Type: String
    Description: >-
      PostHog Firehose endpoint URL. Amazon Data Firehose delivers only to HTTPS endpoints,
      so a self-hosted PostHog must be reachable from AWS over HTTPS.
    AllowedPattern: '^https://.+'
  PostHogAccessKey:
    Type: String
    NoEcho: true
    Description: Your PostHog project API key.
  LogGroupName:
    Type: String
    Description: CloudWatch log group to stream, for example /aws/lambda/checkout-api.
  FilterPattern:
    Type: String
    Default: ''
    Description: >-
      CloudWatch subscription filter pattern. Empty forwards every log line in the group. Set a pattern
      such as ERROR to forward only matching lines and lower the volume Firehose bills you for.
  BufferSizeMB:
    Type: Number
    Default: 1
    MinValue: 1
    MaxValue: 4
    Description: Firehose buffer size in MB. PostHog rejects a delivery above 8 MB, and Firehose base64-encodes each record on the way out, so 1 leaves room for that.
  BufferIntervalSeconds:
    Type: Number
    Default: 60
    MinValue: 0
    MaxValue: 900
    Description: Firehose buffer interval in seconds.
  RetryDurationSeconds:
    Type: Number
    Default: 300
    MinValue: 0
    MaxValue: 7200
    Description: How long Firehose retries a failed delivery before writing it to the backup bucket.

Resources:
  BackupBucket:
    Type: AWS::S3::Bucket
    # Firehose may have written failed deliveries here; a non-empty bucket would otherwise block stack deletion.
    DeletionPolicy: Retain
    UpdateReplacePolicy: Retain
    Properties:
      BucketEncryption:
        ServerSideEncryptionConfiguration:
          - ServerSideEncryptionByDefault:
              SSEAlgorithm: AES256
      PublicAccessBlockConfiguration:
        BlockPublicAcls: true
        BlockPublicPolicy: true
        IgnorePublicAcls: true
        RestrictPublicBuckets: true
      LifecycleConfiguration:
        Rules:
          - Id: ExpireFailedDeliveries
            Status: Enabled
            ExpirationInDays: 14
            # Firehose writes via multipart upload; an aborted part is invisible to the
            # expiry rule above and bills until it is removed.
            AbortIncompleteMultipartUpload:
              DaysAfterInitiation: 7

  BackupBucketPolicy:
    Type: AWS::S3::BucketPolicy
    Properties:
      Bucket: !Ref BackupBucket
      PolicyDocument:
        Version: '2012-10-17'
        Statement:
          - Sid: DenyInsecureTransport
            Effect: Deny
            Principal: '*'
            Action: s3:*
            Resource:
              - !GetAtt BackupBucket.Arn
              - !Sub '${BackupBucket.Arn}/*'
            Condition:
              Bool:
                aws:SecureTransport: false

  # Firehose writes PostHog's response here when a delivery fails, which is what
  # the stream's Error logs tab reads.
  FirehoseErrorLogGroup:
    Type: AWS::Logs::LogGroup
    Properties:
      LogGroupName: !Sub /aws/kinesisfirehose/${AWS::StackName}
      RetentionInDays: 7

  HttpEndpointErrorLogStream:
    Type: AWS::Logs::LogStream
    Properties:
      LogGroupName: !Ref FirehoseErrorLogGroup
      LogStreamName: HttpEndpointDelivery

  S3ErrorLogStream:
    Type: AWS::Logs::LogStream
    Properties:
      LogGroupName: !Ref FirehoseErrorLogGroup
      LogStreamName: S3Delivery

  FirehoseRole:
    Type: AWS::IAM::Role
    Properties:
      AssumeRolePolicyDocument:
        Version: '2012-10-17'
        Statement:
          - Effect: Allow
            Principal:
              Service: firehose.amazonaws.com
            Action: sts:AssumeRole
            Condition:
              StringEquals:
                sts:ExternalId: !Ref AWS::AccountId
      Policies:
        - PolicyName: WriteBackupBucket
          PolicyDocument:
            Version: '2012-10-17'
            Statement:
              - Effect: Allow
                Action:
                  - s3:AbortMultipartUpload
                  - s3:GetBucketLocation
                  - s3:ListBucket
                  - s3:ListBucketMultipartUploads
                  - s3:PutObject
                Resource:
                  - !GetAtt BackupBucket.Arn
                  - !Sub '${BackupBucket.Arn}/*'
        - PolicyName: WriteErrorLogs
          PolicyDocument:
            Version: '2012-10-17'
            Statement:
              - Effect: Allow
                Action: logs:PutLogEvents
                Resource: !Sub 'arn:${AWS::Partition}:logs:${AWS::Region}:${AWS::AccountId}:log-group:${FirehoseErrorLogGroup}:log-stream:*'

  DeliveryStream:
    Type: AWS::KinesisFirehose::DeliveryStream
    Properties:
      DeliveryStreamType: DirectPut
      DeliveryStreamEncryptionConfigurationInput:
        KeyType: AWS_OWNED_CMK
      HttpEndpointDestinationConfiguration:
        EndpointConfiguration:
          Name: PostHog
          Url: !Ref PostHogEndpointUrl
          AccessKey: !Ref PostHogAccessKey
        RequestConfiguration:
          ContentEncoding: GZIP
        BufferingHints:
          SizeInMBs: !Ref BufferSizeMB
          IntervalInSeconds: !Ref BufferIntervalSeconds
        RetryOptions:
          DurationInSeconds: !Ref RetryDurationSeconds
        RoleARN: !GetAtt FirehoseRole.Arn
        CloudWatchLoggingOptions:
          Enabled: true
          LogGroupName: !Ref FirehoseErrorLogGroup
          LogStreamName: !Ref HttpEndpointErrorLogStream
        S3BackupMode: FailedDataOnly
        S3Configuration:
          BucketARN: !GetAtt BackupBucket.Arn
          RoleARN: !GetAtt FirehoseRole.Arn
          Prefix: failed/
          CompressionFormat: GZIP
          CloudWatchLoggingOptions:
            Enabled: true
            LogGroupName: !Ref FirehoseErrorLogGroup
            LogStreamName: !Ref S3ErrorLogStream

  LogsToFirehoseRole:
    Type: AWS::IAM::Role
    Properties:
      AssumeRolePolicyDocument:
        Version: '2012-10-17'
        Statement:
          - Effect: Allow
            Principal:
              Service: !Sub logs.${AWS::Region}.${AWS::URLSuffix}
            Action: sts:AssumeRole
            Condition:
              ArnLike:
                aws:SourceArn: !Sub arn:${AWS::Partition}:logs:${AWS::Region}:${AWS::AccountId}:*
      Policies:
        - PolicyName: PutToDeliveryStream
          PolicyDocument:
            Version: '2012-10-17'
            Statement:
              - Effect: Allow
                Action:
                  - firehose:PutRecord
                  - firehose:PutRecordBatch
                Resource: !GetAtt DeliveryStream.Arn

  SubscriptionFilter:
    Type: AWS::Logs::SubscriptionFilter
    Properties:
      LogGroupName: !Ref LogGroupName
      FilterPattern: !Ref FilterPattern
      DestinationArn: !GetAtt DeliveryStream.Arn
      RoleArn: !GetAtt LogsToFirehoseRole.Arn

Outputs:
  DeliveryStreamArn:
    Description: Point additional subscription filters at this stream to include more log groups.
    Value: !GetAtt DeliveryStream.Arn
  LogsToFirehoseRoleArn:
    Description: Role to reuse for additional subscription filters.
    Value: !GetAtt LogsToFirehoseRole.Arn
  BackupBucketName:
    Description: Deliveries that PostHog could not accept land here.
    Value: !Ref BackupBucket
  ErrorLogGroupName:
    Description: Firehose writes PostHog's response here when a delivery fails.
    Value: !Ref FirehoseErrorLogGroup
```

## Set it up with Terraform

The configuration below creates the same resources as the CloudFormation template, and takes any number of log groups. Each log group gets its own filter pattern, so you can forward everything from one service and only warnings and errors from a noisy one.

1. Save it as `posthog-cloudwatch-logs.tf` in an empty directory.
2. Save your settings next to it as `terraform.tfvars`, using the example below.
3. Run `terraform init`, then `terraform apply`.

Terraform keeps your project API key in its state, so store the state somewhere private.

```hcl
# terraform.tfvars
posthog_access_key = "phc_your_project_api_key"

# For PostHog Cloud EU:
# posthog_endpoint_url = "https://eu.i.posthog.com/i/v1/logs/aws/firehose"

log_groups = {
  # An empty pattern forwards every line.
  "/aws/lambda/checkout" = ""

  # Plain-text logs: forward lines that contain ERROR or WARN.
  "/aws/ecs/search-indexer" = "?ERROR ?WARN"

  # JSON logs: forward events whose level is error or warn.
  "/aws/lambda/image-resize" = "{ $.level = \"error\" || $.level = \"warn\" }"
}
```

Filter patterns are case-sensitive. See the [CloudWatch filter pattern syntax](https://docs.aws.amazon.com/AmazonCloudWatch/latest/logs/FilterAndPatternSyntax.html) for more ways to match.

To add or remove a log group, edit `log_groups` and run `terraform apply` again.

```hcl
# Streams CloudWatch log groups into PostHog Logs through an Amazon Data Firehose
# HTTP endpoint destination, with one subscription filter per entry in log_groups.
#
# The project API key is stored in Terraform state, so keep state somewhere private.

terraform {
  required_version = ">= 1.3"
  required_providers {
    aws = {
      source  = "hashicorp/aws"
      version = ">= 6.0"
    }
  }
}

variable "posthog_endpoint_url" {
  type        = string
  default     = "https://us.i.posthog.com/i/v1/logs/aws/firehose"
  description = "PostHog Firehose endpoint URL. Use https://eu.i.posthog.com/i/v1/logs/aws/firehose for PostHog Cloud EU."
  validation {
    condition     = startswith(var.posthog_endpoint_url, "https://")
    error_message = "Amazon Data Firehose delivers only to HTTPS endpoints."
  }
}

variable "posthog_access_key" {
  type        = string
  sensitive   = true
  description = "Your PostHog project API key."
}

variable "log_groups" {
  type        = map(string)
  description = "CloudWatch log groups to stream, each mapped to a subscription filter pattern. An empty pattern forwards every log line."
}

variable "stream_name" {
  type        = string
  default     = "posthog-logs"
  description = "Name of the Firehose stream. Also prefixes the bucket and role names."
}

variable "buffer_size_mb" {
  type        = number
  default     = 1
  description = "Firehose buffer size in MB."
  validation {
    condition     = var.buffer_size_mb >= 1 && var.buffer_size_mb <= 4
    error_message = "PostHog rejects a delivery above 8 MB, and Firehose base64-encodes records on the way out. Keep this between 1 and 4."
  }
}

variable "buffer_interval_seconds" {
  type        = number
  default     = 60
  description = "Firehose buffer interval in seconds."
}

variable "retry_duration_seconds" {
  type        = number
  default     = 300
  description = "How long Firehose retries a failed delivery before writing it to the backup bucket."
}

data "aws_caller_identity" "current" {}
data "aws_region" "current" {}
data "aws_partition" "current" {}

locals {
  account_id = data.aws_caller_identity.current.account_id
  region     = data.aws_region.current.region
  partition  = data.aws_partition.current.partition
  dns_suffix = data.aws_partition.current.dns_suffix
}

# force_destroy stays false, so `terraform destroy` fails on a non-empty bucket
# instead of deleting failed deliveries.
resource "aws_s3_bucket" "backup" {
  bucket_prefix = "${var.stream_name}-backup-"
}

resource "aws_s3_bucket_server_side_encryption_configuration" "backup" {
  bucket = aws_s3_bucket.backup.id
  rule {
    apply_server_side_encryption_by_default {
      sse_algorithm = "AES256"
    }
  }
}

resource "aws_s3_bucket_public_access_block" "backup" {
  bucket                  = aws_s3_bucket.backup.id
  block_public_acls       = true
  block_public_policy     = true
  ignore_public_acls      = true
  restrict_public_buckets = true
}

resource "aws_s3_bucket_lifecycle_configuration" "backup" {
  bucket = aws_s3_bucket.backup.id
  rule {
    id     = "ExpireFailedDeliveries"
    status = "Enabled"
    filter {}
    expiration {
      days = 14
    }
    # Firehose writes via multipart upload; an aborted part is invisible to the
    # expiry rule above and bills until it is removed.
    abort_incomplete_multipart_upload {
      days_after_initiation = 7
    }
  }
}

resource "aws_s3_bucket_policy" "backup" {
  bucket = aws_s3_bucket.backup.id
  policy = jsonencode({
    Version = "2012-10-17"
    Statement = [{
      Sid       = "DenyInsecureTransport"
      Effect    = "Deny"
      Principal = "*"
      Action    = "s3:*"
      Resource  = [aws_s3_bucket.backup.arn, "${aws_s3_bucket.backup.arn}/*"]
      Condition = { Bool = { "aws:SecureTransport" = "false" } }
    }]
  })
  depends_on = [aws_s3_bucket_public_access_block.backup]
}

# Firehose writes PostHog's response here when a delivery fails, which is what
# the stream's Error logs tab reads.
resource "aws_cloudwatch_log_group" "firehose_errors" {
  name              = "/aws/kinesisfirehose/${var.stream_name}"
  retention_in_days = 7
}

resource "aws_cloudwatch_log_stream" "http_errors" {
  name           = "HttpEndpointDelivery"
  log_group_name = aws_cloudwatch_log_group.firehose_errors.name
}

resource "aws_cloudwatch_log_stream" "s3_errors" {
  name           = "S3Delivery"
  log_group_name = aws_cloudwatch_log_group.firehose_errors.name
}

resource "aws_iam_role" "firehose" {
  name_prefix = "${var.stream_name}-firehose-"
  assume_role_policy = jsonencode({
    Version = "2012-10-17"
    Statement = [{
      Effect    = "Allow"
      Principal = { Service = "firehose.amazonaws.com" }
      Action    = "sts:AssumeRole"
      Condition = { StringEquals = { "sts:ExternalId" = local.account_id } }
    }]
  })
}

resource "aws_iam_role_policy" "firehose_write_backup" {
  name = "WriteBackupBucket"
  role = aws_iam_role.firehose.id
  policy = jsonencode({
    Version = "2012-10-17"
    Statement = [{
      Effect = "Allow"
      Action = [
        "s3:AbortMultipartUpload",
        "s3:GetBucketLocation",
        "s3:ListBucket",
        "s3:ListBucketMultipartUploads",
        "s3:PutObject",
      ]
      Resource = [aws_s3_bucket.backup.arn, "${aws_s3_bucket.backup.arn}/*"]
    }]
  })
}

resource "aws_iam_role_policy" "firehose_write_error_logs" {
  name = "WriteErrorLogs"
  role = aws_iam_role.firehose.id
  policy = jsonencode({
    Version = "2012-10-17"
    Statement = [{
      Effect   = "Allow"
      Action   = "logs:PutLogEvents"
      Resource = "${aws_cloudwatch_log_group.firehose_errors.arn}:log-stream:*"
    }]
  })
}

resource "aws_kinesis_firehose_delivery_stream" "posthog" {
  name        = var.stream_name
  destination = "http_endpoint"

  server_side_encryption {
    enabled  = true
    key_type = "AWS_OWNED_CMK"
  }

  http_endpoint_configuration {
    name               = "PostHog"
    url                = var.posthog_endpoint_url
    access_key         = var.posthog_access_key
    buffering_size     = var.buffer_size_mb
    buffering_interval = var.buffer_interval_seconds
    retry_duration     = var.retry_duration_seconds
    role_arn           = aws_iam_role.firehose.arn
    s3_backup_mode     = "FailedDataOnly"

    request_configuration {
      content_encoding = "GZIP"
    }

    cloudwatch_logging_options {
      enabled         = true
      log_group_name  = aws_cloudwatch_log_group.firehose_errors.name
      log_stream_name = aws_cloudwatch_log_stream.http_errors.name
    }

    s3_configuration {
      bucket_arn         = aws_s3_bucket.backup.arn
      role_arn           = aws_iam_role.firehose.arn
      prefix             = "failed/"
      compression_format = "GZIP"

      cloudwatch_logging_options {
        enabled         = true
        log_group_name  = aws_cloudwatch_log_group.firehose_errors.name
        log_stream_name = aws_cloudwatch_log_stream.s3_errors.name
      }
    }
  }

  depends_on = [
    aws_iam_role_policy.firehose_write_backup,
    aws_iam_role_policy.firehose_write_error_logs,
  ]
}

resource "aws_iam_role" "logs_to_firehose" {
  name_prefix = "${var.stream_name}-cwl-"
  assume_role_policy = jsonencode({
    Version = "2012-10-17"
    Statement = [{
      Effect    = "Allow"
      Principal = { Service = "logs.${local.region}.${local.dns_suffix}" }
      Action    = "sts:AssumeRole"
      Condition = { ArnLike = { "aws:SourceArn" = "arn:${local.partition}:logs:${local.region}:${local.account_id}:*" } }
    }]
  })
}

resource "aws_iam_role_policy" "logs_put_to_stream" {
  name = "PutToDeliveryStream"
  role = aws_iam_role.logs_to_firehose.id
  policy = jsonencode({
    Version = "2012-10-17"
    Statement = [{
      Effect   = "Allow"
      Action   = ["firehose:PutRecord", "firehose:PutRecordBatch"]
      Resource = aws_kinesis_firehose_delivery_stream.posthog.arn
    }]
  })
}

# One filter per log group, all sharing the same stream and role.
resource "aws_cloudwatch_log_subscription_filter" "posthog" {
  for_each        = var.log_groups
  name            = var.stream_name
  log_group_name  = each.key
  filter_pattern  = each.value
  destination_arn = aws_kinesis_firehose_delivery_stream.posthog.arn
  role_arn        = aws_iam_role.logs_to_firehose.arn

  depends_on = [aws_iam_role_policy.logs_put_to_stream]
}

output "delivery_stream_arn" {
  value = aws_kinesis_firehose_delivery_stream.posthog.arn
}

output "logs_to_firehose_role_arn" {
  value = aws_iam_role.logs_to_firehose.arn
}

output "backup_bucket_name" {
  value = aws_s3_bucket.backup.bucket
}

output "error_log_group_name" {
  value = aws_cloudwatch_log_group.firehose_errors.name
}
```

## Set it up in the console

To set it up by hand:

1. Open **Amazon Data Firehose > Create Firehose stream**. Set the source to **Direct PUT** and the destination to **HTTP Endpoint**.
2. Set the endpoint URL from the table above, and paste your project API key into **Access key**. Use the settings below.
3. Open **CloudWatch > Log groups**, pick a group, and choose **Actions > Subscription filters > Create Amazon Data Firehose subscription filter**. Select the stream and leave the filter pattern empty to forward every line.

Repeat step 3 for each log group you want to send.

### Stream settings

| Setting          | Value            | Why                                                                 |
| ---------------- | ---------------- | ------------------------------------------------------------------- |
| Buffer size      | 1 MB             | Stays under PostHog's 8 MB limit once Firehose encodes the records. |
| Buffer interval  | 60 seconds       | Logs arrive within about a minute.                                  |
| Content encoding | GZIP             | Fewer bytes on the wire.                                            |
| Retry duration   | 300 seconds      | Retries for five minutes before writing to the backup bucket.       |
| S3 backup        | Failed data only | Keeps a copy of what PostHog could not accept.                      |

## What your logs look like

Each CloudWatch log event becomes one log in PostHog. The message is the log body, and the event keeps its original CloudWatch timestamp.

These attributes describe where the log came from. They are the same for every log in a log group:

| Attribute             | Value                                   |
| --------------------- | --------------------------------------- |
| `cloud.provider`      | `aws`                                   |
| `cloud.account.id`    | The AWS account that owns the log group |
| `cloud.region`        | The region the stream runs in           |
| `aws.log.group.name`  | The log group                           |
| `aws.log.stream.name` | The log stream                          |

These describe the individual event:

| Attribute                  | Value                                                      |
| -------------------------- | ---------------------------------------------------------- |
| `aws.log.event.id`         | The id CloudWatch gave the event                           |
| `aws.subscription_filters` | The subscription filters that matched, separated by commas |

**Service name** comes from the log group. `/aws/lambda/checkout-api` becomes `checkout-api`, `/aws/rds/instance/orders-db/postgresql` becomes `orders-db`, and `/aws/vpc/flowlogs` becomes `vpc-flow-logs`. A log group outside the AWS naming conventions keeps its full name, so `my-app-logs` stays `my-app-logs`. To set the name yourself, add a `service.name` common attribute to the Firehose stream.

**Severity** comes from a `level`, `severity`, `log.level`, `config.log_level` or `levelname` key when the message is JSON, checked in that order. In a plain-text line PostHog reads the first three words for a level such as `ERROR`, `WARN` or `DEBUG`, so `ERROR payment declined` and `2026-09-16T10:00:00Z INFO started` both resolve. Common spellings such as `warning`, `err` and `critical` are recognized. Anything else is stored as `info`, so `plain line with error later in it` stays `info`.

Logs appear in the [Logs view](https://app.posthog.com/logs) within a couple of minutes, depending on your buffer settings. Filter by `service.name`, severity, or any of the attributes above.

## Limits and failures

- PostHog rejects a delivery above 8 MB, and Firehose writes it to the backup bucket instead of retrying. A 1 MB buffer stays well under.
- Delivery is at-least-once. If PostHog fails part way through a batch, Firehose resends the whole batch and some lines can appear twice. Copies of the same event share an `aws.log.event.id`, so you can tell a duplicate from two events that happen to carry the same message.
- A record that PostHog can't decode is skipped, and the rest of the batch is still accepted.

## Troubleshooting

**No logs arrive.** Open the stream's **Monitoring** tab in the Firehose console. If `DeliveryToHttpEndpoint.Success` is flat, check the log group's subscription filter exists and points at this stream. If deliveries are failing, the **Error logs** tab shows PostHog's response.

**Every delivery fails with 401.** The access key isn't a valid project API key. Copy it again from **Settings > Project > Project API key**, and check it belongs to the project you're looking at.

**Every delivery fails with 413.** The buffer size is too large for the endpoint. Set it to 1 MB.

**Logs arrive under the wrong service name.** Add a `service.name` common attribute to the Firehose stream, which overrides the name inferred from the log group.
