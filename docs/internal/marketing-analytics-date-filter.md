# Marketing analytics date filter

The shared Marketing analytics dashboard toolbar shows the active date range beside Reload. Users can inspect and change the range without opening Options. The toolbar wraps its controls when space is limited.

Options contains comparison, integrations, and test-account filtering. Attribution and retention explorers keep their existing visible date selectors.

The date selector continues to use the existing shared date state, URL parameters, and time-precision support. Moving it does not change query ranges or aggregation behavior.
