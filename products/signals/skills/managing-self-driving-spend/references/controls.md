# Spend controls

Read the current value before you change anything, and read it back after.
Where no tool exists, give the user the setting name. Most settings are in the Inbox settings, in the Self-driving section.

| Control                     | What it changes                                                                                         | How to change it                                                                                                                                                          | What the user loses                                                                    |
| --------------------------- | ------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| Spend limit                 | A monthly cap. Self-driving work pauses until the next billing period.                                  | Read with `billing-limits-get`. Set it on the billing page. No tool.                                                                                                      | Useful work stops for the rest of the period                                           |
| Daily report limit          | Caps new reports per day in the project timezone. Ingestion, scouts, and research pause until midnight. | "Daily report limit" setting. No tool.                                                                                                                                    | Issues found late in the day wait until tomorrow                                       |
| PR generation               | Whether actionable reports open a pull request automatically                                            | "PR generation" setting. No tool.                                                                                                                                         | Fewer fixes arrive ready to review                                                     |
| Priority threshold          | The lowest report priority that opens a pull request automatically (P0 is highest)                      | "Priority threshold" setting, for the project or under "Your overrides". No tool.                                                                                         | Lower-priority fixes need a manual start                                               |
| Turn off a source           | Stops new signals from that source                                                                      | `inbox-source-configs-partial-update` with `enabled: false`                                                                                                               | Everything that source would find                                                      |
| Pause a scout               | Stops its scheduled runs                                                                                | `scout-config-update` with `enabled: false`                                                                                                                               | Everything that scout would find                                                       |
| Run a scout less often      | Fewer runs                                                                                              | `scout-config-update` with a larger `run_interval_minutes`, or a cron schedule                                                                                            | Findings arrive later                                                                  |
| Steering instructions       | Tells all scouts, research, or implementation what to focus on or skip                                  | `inbox-steering-instructions-get`, then `inbox-steering-instructions-update`. Applies to the whole project, not to one source.                                            | Lowers volume but does not cap it                                                      |
| Error tracking signal types | Choose between new, reopened, and spiking issues                                                        | `inbox-source-configs-partial-update` on the `issue_created`, `issue_reopened`, or `issue_spiking` config                                                                 | Turning off new issues means an issue reaches the inbox only when it spikes or reopens |
| Replay scanners             | Choose which scanners send findings to the inbox                                                        | `vision-scanners-update` with `emits_signals`, `sampling_rate`, or `enabled`                                                                                              | Findings from the scanners you turn down                                               |
| AI evaluation reports       | Fewer or less frequent evaluation reports                                                               | `llma-evaluation-report-update` with `enabled`, `frequency`, or `daily_run_cap`                                                                                           | Also changes that report's email and Slack delivery                                    |
| Anomaly alerts              | Per alert: stop the investigation, or hold back inconclusive results                                    | `alert-update` with `investigation_agent_enabled: false` or `investigation_inconclusive_action: "suppress"`. For all alerts, turn off the `anomaly_investigation` source. | Fewer anomaly reports                                                                  |
| Linear teams                | Only issues from the chosen Linear teams become signals                                                 | `inbox-source-configs-partial-update` with `config.linear_team_ids`                                                                                                       | Issues from other teams                                                                |
