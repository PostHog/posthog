# Sample traces

Sample `$ai_*` events for exercising AI observability locally: conversation trees, sessions, media, and metadata edge cases across SDKs, frameworks and providers.

## Seed a local instance

```bash
python manage.py seed_ai_sample_traces --team-id 1                 # core set
python manage.py seed_ai_sample_traces --team-id 1 --set stress    # layout-breaking cases
python manage.py seed_ai_sample_traces --team-id 1 --set all
python manage.py seed_ai_sample_traces --team-id 1 --only claude_code_plugin_session,api_openai_pdf_url_intake
```

Events go through local capture (`--host`, default `http://localhost:8010`), so ingestion computes cost, extracts tool calls, converts OTel events and offloads media as it does for real SDK traffic.
Each run gets fresh event, trace, span and session ids and recent timestamps, so the command can be repeated.

## Layout

- `units/<id>.json`: one trace or session per file. The id names the shape it covers, for example `openai_agents_web_search_call` or `session_langchain_memory_150_embeddings`. Each file has `title`, `scenario`, `sets`, `why`, a `summary` (event counts, libraries, providers, frameworks, models, content-part types) and `events` (`event`, `offset_ms`, `distinct_id`, `properties` as an SDK sends them).
- `sets.json`: `core` has one unit per common path for checking by hand, `stress` has the cases that break layouts. Every unit is in `all`.
- `media/`: images, PDFs, audio and video the units reference. Inline media appears as `⟦media:<file>⟧` inside a `data:` URI or as raw base64, and URL media points at `https://media.example.com/<file>`. Tools that read the units resolve both: the seed command inlines the base64, and a browser test can route `media.example.com` to this directory.
- `checksums.json`: hashes of every generated file, checked by `test_sample_traces.py`.

## Provenance

Units were selected to cover the shapes seen across production AI events: ingestion paths, content-part types, media carriers, tree and session shapes, errors, and metadata-only events.
Only the structure was kept.
All text, names, identifiers, URLs and media were written or rendered fresh, with reserved `example.*` domains and obviously fake tokens.
The files are regenerated by the AI observability team; do not edit them by hand (see `AGENTS.md`).
