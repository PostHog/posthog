Run `pnpm --filter=@posthog/frontend build:message-preferences` after changing a class, and bump `v` so that browsers and the CDN fetch the new file. A raw path, not the static tag: production storage hashes the file name, and the CDN that serves /static/ holds only the unhashed files from frontend/public, so a hashed URL returns 404. {% endcomment %}
