# Automatic task archiving

Each space can archive inactive tasks after 1, 3, 7, 14, or 30 days, or use a custom threshold from 1 to 365 days. The default is **Never**.

Open a space's options menu and choose **Auto-archive…** to change its rule. Shared-space rules apply to everyone. Personal-space rules apply only to that personal space.

Task activity includes new messages and task-run activity. The server checks hourly and skips pinned tasks, tasks being viewed, and tasks with queued or active runs.

Automatic archiving uses the same shared archive state as manual archiving. It does not automatically unarchive a task. Use the archive view to unarchive a task before continuing it.
