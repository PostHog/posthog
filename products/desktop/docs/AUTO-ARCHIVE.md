# Automatic task archiving

Each space can archive inactive tasks after 1, 3, 7, 14, or 30 days, or use a custom threshold from 1 to 365 days. Automatic archiving is off by default.

Open a space's options menu to see whether auto-archive is on and change its rule. The dialog has a separate on/off control and inactivity threshold. Project admins manage shared-space rules, which apply to everyone. Personal-space rules apply only to that personal space and can be managed by its owner.

Task activity includes new messages and task-run activity. The server checks hourly and skips pinned tasks, tasks being viewed, and tasks with queued or active runs.

Automatic archiving uses the same shared archive state as manual archiving. It does not automatically unarchive a task. Use the archive view to unarchive a task before continuing it.
