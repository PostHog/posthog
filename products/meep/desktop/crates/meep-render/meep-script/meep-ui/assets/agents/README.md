# Agent marks

These are the 128-pixel, optically sized marks used in View’s agent picker. Claude, Codex and OpenCode derive from the [Wake brand assets](https://github.com/iAmCorey/Wake/tree/main/crates/wake/assets/brands). Their MIT notice is in [LICENSE-Wake](LICENSE-Wake).

Gemini, Cursor, Copilot, Droid and Pi use the agents’ artwork from the [ACP Registry](https://github.com/agentclientprotocol/registry). The fx mark comes from [Vercel’s fx brand assets](https://fx.sh/brand). Brand marks belong to their respective owners.
