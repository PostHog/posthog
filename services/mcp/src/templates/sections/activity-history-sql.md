For SQL history reads, use `execute-sql` over `system.activity_logs` only when schema discovery exposes that table. Use scope, item, and `created_at` bounds, select only needed columns, and cap results with `LIMIT 10`. Treat a full page as partial history. SQL enforces the same entitlement, retention, and access controls; it is not a bypass. If the table is unavailable or access is denied, skip this lens rather than trying other audit endpoints.
