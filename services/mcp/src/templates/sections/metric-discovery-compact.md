**Metrics & SQL trust**: for any metric question (business or operational), and before writing SQL or joins, run `learn analytics` — the catalog defines governed metrics (`system.information_schema.metrics`), certified tables/views, and verified joins. Check it before insights or raw SQL and state the outcome in query context. Derived a reusable, recurring measure that the catalog does not define? Offer to save it with `data-catalog-metric-create` — it lands in `proposed` status — when the user asked for it or you have seen it reused at least twice.
