npm/hog: minor

`hog setup` now gives coding agents the exact login and wrap-up messages to send you, so you always get the link, the sign-up and region notes, and what to try next. When you pick session replay or error tracking, setup turns on session recording or exception capture in your project, and the install step names the skill for each other product you picked. A login you reject in the browser now ends the setup with a clear message, instead of an agent installing PostHog without a token.
