# Text font families that the v4 renderer ships, so that a block names them and the fetcher does not fetch them.
#
# One family name per line, as the font-family descriptor of an @font-face rule names it. Only ASCII letters, digits
# and single spaces. The recorder compares names without case and reads a run of whitespace as one space. A blank line
# and a line that starts with "#" are ignored.
#
# Each src URL of an @font-face rule whose family is on this list becomes fonturl:v4:bundled:{slug}, where the slug is
# the name in lowercase with "-" for each space. The renderer must hold each family here in every weight and style,
# and pick the face from the rule's font-weight and font-style descriptors.
#
# List only text families whose licence lets the renderer image carry them: SIL OFL, Apache 2.0 or the Ubuntu Font
# Licence. Never list an icon font. An icon font puts its glyphs at private code points that move between versions,
# so a bundled copy can draw the wrong icon. The fetcher fetches those.
#
# replay-core-v4 embeds this file, so a change ships with a recorder image build. A malformed or repeated line fails
# the crate's tests.
