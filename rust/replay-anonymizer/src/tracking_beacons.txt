# Advertising and analytics beacons. The replay collector and the image fetcher refuse these.
#
# One entry per line: <host pattern><path prefix>
#   host pattern  an exact host, "*.example.com" for every host below example.com, or "*" for every host
#   path prefix   starts with "/" and is compared case-insensitively with the start of the decoded
#                 request path. A prefix that does not end with "/" must end at a segment boundary,
#                 so "host/tr" refuses "/tr" and "/tr/x" but not "/trending/x". "/" alone matches
#                 every path on the host, and "*/" alone is refused.
# A line that starts with "#" and a blank line are ignored.
#
# url_policy.rs embeds this file. The mirror refuses a match when it collects a URL, and the
# fetcher refuses a match again for every job it reads from the frontier, so an entry added here
# also drains the queued backlog for that beacon without a request. A change here ships only with
# an image build of both lanes. A malformed line fails the crate's tests.
